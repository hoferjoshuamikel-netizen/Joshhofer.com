## A simple note to include with each batch

Name the project or employer. Say what each photograph shows, who took it, the approximate date, what you personally did, and whether it is cleared for the public website. For team work, name the collaborators to credit. A short text file is enough; filenames do not need to follow a rigid convention.

Keep original-resolution photographs and uncompressed source video when available. A landscape view plus a portrait-friendly close-up gives the page room to adapt to phones. For video, 10–30 seconds of the real system doing something is a useful first addition. Add captions or a brief transcript where speech matters.
